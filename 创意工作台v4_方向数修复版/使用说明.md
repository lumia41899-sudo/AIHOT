## v1 · 四项 QA 门禁（上一轮，已含在本包）

1. **QA 分批审核 + 覆盖率硬校验**：按每组 4 条分批送审；缺谁补审谁；两轮仍缺 → 标记「需改：审核结果缺失」，绝不进 FINAL；交付页显示「审核覆盖 N/M」；「AI 修复」同步分批。
2. **结构指纹批次门禁**：指纹数不足（同骨架换词）→ 按 8 种结构池自动差异化重写；修复后仍不足 → 全部存疑 + BLOCKED。
3. **时长校准 Gate**：脚本总时长与锁定时长偏差 >2s → 按镜头重分配（首镜 ≤3s），纯代码执行。
4. **一句话解析**：产品名不再被误选为平台（「百度网盘」≠「百度」平台）。

## v2 · 五项流程与格式修复（本轮新增）

### ⑤ 脚本输出格式对齐参考 xlsx（口播/剧情两套模板）
- **原缺陷**：所有脚本强制「上1/3字幕；中1/3…」三段构图排版说明，无头部信息，格式与实际交付表不符。
- **修复**（scripts 提示词重写 + 渲染/导出配套）：
  - **剧情模板**：多人剧情（横屏）；台词带说话人前缀（男：/女：），对白有来有回，末镜面对镜头说 CTA；画面为自然动作描述。
  - **口播模板**：单人口播（竖屏）；连续长段口语自述，不带说话人前缀。
  - 每条脚本新增 **header 头部信息**：演员需求 / 人物关系 / 主要场景 / 服装 / 道具 / 视频风格。
  - 生成脚本卡片、交付总表、Excel 导出均显示头部信息行。
  - 剧情每条 5-8 镜、口播每条 1-3 镜（原为全体 4-6 镜）。

### ⑥ 确认页（第④步）不再覆盖你的选择 + 绿色标明 + 新增输入框
- **原缺陷**：第③步 AI 解析结果无条件覆盖第②步用户选择；「接受推荐」是主按钮、容易误点；返回再前进选项会变；没有创作方向填写框；没有受众输入。
- **修复**：
  - **用户改过的字段优先级最高**：第②步表单 diff 快照（__touched），AI 解析只补空缺字段，绝不覆盖你的选择。
  - **解析缓存**：从第④步返回第②步再回来，Brief 原文没变就不重新解析——选项不再"回来就变"。
  - 第④步改名「确认创作方案」：**绿色「你的选择」标签/角标 = 你自己确定的**；灰色「AI 推荐」= AI 补充项；你亲手点过的选项即时标绿。
  - 按钮对调：**主按钮 = 「✅ 按我确认的来（含 N 处你的选择）」**，接受 AI 推荐降为次要按钮。
  - 新增 **目标受众** 输入框（AI 洞察将按此分析）与 **创作方向 / 补充要求** 输入框（进入策略与脚本生产），两者均进 Lock。

### ⑦ 热点时效校验（时间不准问题）
- **原缺陷**：模型把几个月前的旧知识当"当前热点"（实测混入 2026-06 日期），时间口径错误。
- **修复**：
  - 提示词写死**今天的真实日期**与 30 天窗口边界，要求优先最近 7 天；不确定日期宁可不输出，严禁编造。
  - **客户端硬拦截**：>30 天 / 未来日期 / 无日期的热点与风向一律剔除，剔除条目在页面上红框公示。
  - 每条勾选项带时效标签：**绿色「7天内」** / 灰「N天前」。

### ⑧ 用户洞察/受众必须绑定 Brief
- **原缺陷**：洞察只看产品记忆，不看 Brief 原文，受众经常跑偏。
- **修复**（insight 提示词重写）：Brief 原文 + 受众字段 + 创作方向作为最高优先级注入；受众为空时按 Brief 推断且核心洞察必须以「依据 Brief：…」开头；每条痛点必须对应 Brief 中的人群/场景/卖点之一。

### ⑨ 勾选热点逐一出方向、脚本按方向分组
- **原缺陷**：勾了 3 个热点，策略仍只出 3 个泛化方向、脚本不按热点区分。
- **修复**：
  - strategy 提示词：**勾了几个热点就出几个以上方向**（max(3, 热点数)），每个方向必须绑定一个热点（hotspotRef 原文），方向卡与确认页均显示「对应热点」。
  - matrix 提示词：每条脚本标注 direction（方向清单轮转分配）。
  - scripts 提示词：每条脚本严格按其 direction 对应的热点/立意创作，方向明细随批注入。

## v3 · 运行级能力（本轮新增）

### 运行日志（规范 5.2 Workflow Run Log）
- 右侧 Project Context 面板新增「📜 运行日志」（默认展开），按时间倒序记录：节点流转 / 用户确认（Lock、卖点口径、趋势采用、创作方向）/ 批次心跳 / 审核结果 / FINAL·BLOCKED / 回滚 / 版本操作。
- `goto` 与 `log` 自动记录，关键确认点显式埋事件（带「用户确认」标记），每项目保留最近 300 条。

### 版本管理（规范 23）
- **FINAL 自动存版本**：首次交付时自动快照（内容与上一版本相同则跳过，不重复占位）。
- 交付页新增：**📸 存为版本**（手动快照，最多保留 10 个）、**🔍 与当前对比**（逐脚本显示标题/镜头数/台词是否修改）、**⏪ 恢复此版本**（两段式确认；恢复前当前稿自动存为版本，恢复后自动清空审核结果并回到 QA 重审——规范要求恢复后重跑受影响 Gate）。

### 回滚路由（规范 21 审核回滚协议）
- BLOCKED 时按审核问题关键词映射最早根因节点：结构同质→生成脚本；产品事实/卖点→产品信息；人群/洞察→用户洞察；方向/热点→创意策略；CTA→创意策略。页面显示「📍 回滚建议」及原因，一键「按建议回滚」并记入运行日志。

### 演示大脑对齐 v2 新格式
- 无模型兜底的演示样本同步改为 xlsx 口径：剧情（男：/女：前缀、5 镜、header 头部、横屏）/ 口播（长段自述、3 镜、竖屏），批次含 direction 对象也能正确解析编号。

## v4 · 研究中心实体化（本轮新增）

### 产品记忆 · 事实状态体系（规范 7.1）
- 产品编辑对话框新增「产品事实」清单（每行：标题｜详情｜状态），状态=**已验证/待验证/冲突/禁止使用**。
- 产品卡片显示状态芯片统计（已验证 N · 待验证 N · 冲突 N · 禁止使用 N）。
- 工作流 n1「产品信息」节点把产品记忆的事实清单带状态展示在事实卡上方；冲突/禁止使用项明确标注"不得当作可用口径"。
- 事实清单随产品对象进入 n1 的生成上下文（提示词自动携带）。

### 案例研究中心实体化（规范 8）
- 录入/编辑案例：标题、行业、平台、来源链接、发布时间 + **拉片四件套**（Hook 拆解 / 叙事结构·剧情发动机 / CTA 分析 / 笔记）+ 可复用元素。
- 列表按行业筛选；每张卡显示拉片摘要与可复用元素标签。
- **一键沉淀为资产**（用户主动触发）：Hook→Hook 资产、结构→结构模板、CTA→CTA 模型、可复用元素→组件；来源统一标注「案例沉淀：案例名」，案例打「已沉淀」标记。

### 创意资产中心实体化（规范 9）
- 十一类资产：Hook / 结构模板 / 句式表达 / 剧情机制 / 冲突模型 / 信息差模型 / CTA 模型 / 镜头创意 / 人物关系 / 组件 / 灵感碎片。
- 按类型筛选（只显示有内容的类型），新建资产（类型+内容+来源备注）、删除。
- **灵感速记**：一句话/链接/标签 → 存为「灵感碎片」；默认只是灵感，不自动变成案例或模型（规范 9.2）。
